##  Project Overview

This project is a simple interactive image gallery developed using HTML, CSS, and JavaScript as part of a Coursera JavaScript assignment.

The gallery allows users to interact with images using mouse hover events. When the mouse moves over an image, it updates the displayed image, and when the mouse leaves, the original image is restored.

##  Features

- Interactive image gallery.
- Image changes on mouse hover.
- Original image is restored when the mouse leaves.
- Simple and user-friendly interface.
- Dynamic functionality using JavaScript event handlers.

##  Technologies Used

- **HTML5** – Structure of the webpage.
- **CSS3** – Styling and layout.
- **JavaScript** – Interactive functionality and mouse events.

##  Project Structure

```text
javascript-image-gallery/
│

```

##  How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server or any web browser.
4. Hover over the images to see the interactive functionality.

##  Learning Outcomes

- Understanding JavaScript event handlers.
- Working with mouseover and mouseleave events.
- Dynamically updating HTML image elements.
- Connecting HTML, CSS, and JavaScript files.
